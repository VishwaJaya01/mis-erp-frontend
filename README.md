
# ERP System Login Frame

React + Vite implementation of the ERP System Login Frame design (https://www.figma.com/design/sK0BRUGhX7UfO8JlfVNtpQ/ERP-System-Login-Frame). The project now ships with a cleaned TypeScript codebase, updated dependencies, and a simplified Vite configuration.

## Prerequisites

- Node.js ≥ 18
- npm ≥ 10 (ships with Node 18+)

## Getting Started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the dev server (opens on http://localhost:3000)

   ```bash
   npm run dev
   ```

## Additional Scripts

- `npm run build` – generate a production build in `build/`
- `npm run preview` – preview the production build locally

## Project Notes

- Source lives under `src/` with an `@/*` path alias configured for imports.
- UI primitives use Radix UI, lucide-react icons, and supporting libraries such as `sonner`, `cmdk`, and `vaul`.
- Build output is redirected to `build/`; the directory is ignored by Git.
